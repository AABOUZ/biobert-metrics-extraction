# biobert-metrics-extraction
NLP pipeline based on BioBERT for extracting of AI evaluation metrics from biomedical research articles.

# BioBERT – Metrics Extraction

Projet de Master 2 SiVOS (Université de Rennes).

Objectif :
Extraire automatiquement les métriques d’évaluation
(Accuracy, F1, AUC, etc.) depuis des articles biomédicaux.

Techno :
- Python
- HuggingFace Transformers
- BioBERT
